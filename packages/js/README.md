# MaterialDesignColor for JavaScript / TypeScript

Material Design 3 preset color schemes (light/dark, 48 standard roles + 8 custom status roles) and the classic Material 2 palette as plain TypeScript constants.

This package is **framework-agnostic** — pure TS with no runtime dependencies. Works in:
- **React Native / Expo** (Metro consumes the published `dist/` ESM output)
- Plain React, Vue, Svelte, vanilla web
- Node.js (ESM, 16+), Deno, Bun

The package is published as **ESM-only** (`"type": "module"`). CommonJS consumers can use a dynamic `await import("@swift-man/material-design-color")` or migrate to ESM. No native modules, no Expo config plugins, no prebuild required.

## Install

```bash
npm install @swift-man/material-design-color
# or
yarn add @swift-man/material-design-color
# or
pnpm add @swift-man/material-design-color
```

## Usage

### Material 3 preset color schemes

```ts
import { createMaterialTheme, getMaterialThemeKeyColors } from "@swift-man/material-design-color";

const theme = createMaterialTheme({ preset: "expressive", dark: false });
const primary = theme.colorScheme.primary;          // "#006B5A"
const onPrimaryContainer = theme.colorScheme.onPrimaryContainer;
const keyPrimary = getMaterialThemeKeyColors("expressive").primary;
```

Available presets: `tonalSpot`, `fidelity`, `content`, `monochrome`, `neutral`, `vibrant`, `expressive`, `rainbow`, `fruitSalad`.

### Material Theme Builder color schemes

Paste role colors from Material Theme Builder into `colorScheme`. Missing roles fall back to the selected preset.

```ts
import { createMaterialTheme } from "@swift-man/material-design-color";

const theme = createMaterialTheme({
  preset: "tonalSpot",
  colorScheme: {
    primary: "#6750A4",
    onPrimary: "#FFFFFF",
    primaryContainer: "#EADDFF",
    onPrimaryContainer: "#21005D",
    surface: "#FFFBFE",
    onSurface: "#1C1B1F",
  },
});
```

### Material 2 palette

```ts
import { colors } from "@swift-man/material-design-color";

const backgroundColor = colors.pink400;             // "#EC407A"
const accent = colors.tealA700;                     // "#00BFA5"
```

### React Native / Expo

```tsx
import { createMaterialTheme, colors } from "@swift-man/material-design-color";
import { View, Text } from "react-native";

const theme = createMaterialTheme({ preset: "fruitSalad", dark: true });

export function Example() {
  return (
    <View style={{ backgroundColor: theme.colorScheme.surface }}>
      <Text style={{ color: theme.colorScheme.onSurface }}>Hello</Text>
      <View style={{ backgroundColor: colors.tealA700 }} />
    </View>
  );
}
```

### Plain web

```ts
import { getMaterialTheme } from "@swift-man/material-design-color";

document.body.style.backgroundColor = getMaterialTheme("neutral").colorScheme.surface;
```

### Node / Deno / Bun

```ts
import { colors, lightColorScheme } from "@swift-man/material-design-color";

console.log(colors.blue500);              // "#2196F3"
console.log(lightColorScheme.primary);    // "#65558F"
```

## Cross-language consistency

The hex values here are generated from the same JSON tokens as the iOS Swift package and the Python package, so a `colors.pink400` in your RN app is byte-identical to `MaterialPalette.pink400` on iOS and `colors.pink400` in Python. Useful when you ship the same product across stacks.

## Material 3 color roles

See the [shared color role guide](../../README.md#material-3-color-roles) for Google-defined role meanings, fill/content pairings, surface and fixed roles, and platform naming conventions. All platforms use the same 48 standard role tokens plus 8 separate custom status roles.


## Extended success / warning roles

```ts
import { createMaterialTheme, materialExtendedColorRoles } from '@swift-man/material-design-color';
const theme = createMaterialTheme({ dark: false });
const safe = theme.colorScheme.success;
const text = theme.colorScheme.onSuccess;
const caution = theme.colorScheme.warningContainer;
const cautionText = theme.colorScheme.onWarningContainer;
const custom = createMaterialTheme({colorScheme: {success: '#006D37', onSuccess: '#FFFFFF'}});
```

The standard `materialColorSchemeRoles` and `MaterialColorRole` retain 48 roles. `materialExtendedColorRoles` / `MaterialExtendedColorRole` list 8 custom roles; factory results use `MaterialThemeWithExtended` and `MaterialColorSchemeWithExtended`, preserving existing manually constructed `MaterialTheme` values. Python exposes the same role names through role lookup and uses snake_case properties. Preset data stays deeply frozen. See the [shared guide](../../README.md#macos-swiftui-and-extended-status-colors-22) for pairings and contrast guarantees.

For a different seed, use the [build-time tool](../../README.md#generate-a-brand-theme-at-build-time) and load its JSON:

```ts
// brand.json is generated by tools/theme, and contains light/dark + extended.light/dark.
const scheme = {...brand.light, ...brand.extended.light};
const brandTheme = createMaterialTheme({colorScheme: scheme});
// createMaterialTheme sourceColor remains preset metadata; brand.sourceColor is the generated seed.
```


## App-owned final colors (2.3)

Presets and success/warning values are templates. The app owns final product values and supplies them through `createMaterialTheme({colorScheme: ...})`. Runtime overrides do not harmonize or modify the supplied hex. `getSchemeColor` now supports extended roles on a complete factory scheme while preserving the standard-only overload:

```ts
import {createMaterialTheme, getSchemeColor} from '@swift-man/material-design-color';
const theme = createMaterialTheme({colorScheme: {warning: '#804000', onWarning: '#FFFFFF'}});
const warning = getSchemeColor(theme.colorScheme, 'warning');
```

See the [shared responsibility guide](../../README.md#템플릿-값과-앱-확정-값). Contrast validation is available in Swift Core, JavaScript/TypeScript, and Python starting with 2.4.0; see the examples below.

### 앱 최종 색상 대비 검증 (2.4.0)

```ts
import { createMaterialTheme, contrastRatio, contrastIssues } from '@swift-man/material-design-color';
import type { MaterialContrastIssue } from '@swift-man/material-design-color';

const theme = createMaterialTheme({
  colorScheme: { warning: '#804000', onWarning: '#FFFFFF' },
});
console.log(contrastRatio('#804000', '#FFFFFF'));
try {
  const issues: readonly MaterialContrastIssue[] = contrastIssues(theme.colorScheme, 4.5);
  console.log(issues); // { colorRole, onRole, ratio }[], camelCase 역할 이름
} catch (error) {
  if (error instanceof RangeError) console.error('대비 기준은 유한한 1...21이어야 합니다.');
  else throw error;
}
```

`contrastRatio`는 불투명 sRGB `#RRGGBB` 두 색의 WCAG 2.x 비율(1...21)을 계산합니다.
잘못된 hex에는 `TypeError`, `contrastIssues`의 잘못된 기준에는 `RangeError`를 던집니다.
기본 31개·확장 4개 의미상 대비 쌍을 검사하며 결과 배열과 진단 객체는 동결됩니다.
기존 48개 역할 스킴은 확장 쌍을 생략합니다. 확장 쌍의 한쪽만 있으면 `TypeError`입니다.
실제 화면의 임의 인접 관계는 추론하지 않으며 투명 색은 배경과 합성한 뒤 검사하세요.
